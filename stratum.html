The story

Why did I build this tool?

Simple: Stratum started as a personal tool I built while making terrain packs. The thing is, I spent far more time juggling between software than actually working in it: exporting each variant, renaming files, organizing folders, re-importing everything into the game engine, building materials... I repeated the same clicks for hours on every pack, it was a huge time sink. So I automated the process, step by step, until a single click did it all. Today every Kalysteon pack goes through this tool, and now it's yours to use. Hopefully it helps you too!
